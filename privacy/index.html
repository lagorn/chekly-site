Политика конфиденциальности приложения Chekly

Дата вступления в силу: 22 октября 2026 г. · English

Chekly — мобильное приложение для учёта трат по электронным чекам из вашей почты. Разработчик: Александр Алтухов (Aleksandr Altukhov). Связаться: chekly-help@yandex.com.

Какие данные обрабатывает приложение

  • Адреса подключённых почт — их сообщают Mail.ru, Яндекс или Google при входе.
  • Доступ к почте. Вход выполняется на сайте почтового сервиса; приложение получает от него ключ доступа (токен), а ваш пароль не видит и не хранит.
  • Письма с электронными чеками. Приложение ищет только письма от отправителей кассовых чеков; остальные письма не открывает.
  • Данные чеков: магазин, дата, товары, количество и суммы, реквизиты чека.

Где хранятся данные

Все данные хранятся только на вашем устройстве: чеки — в базе данных приложения на телефоне, ключ доступа к почте — в защищённом хранилище системы. У Chekly нет своего сервера: данные не передаются разработчику и третьим лицам, кроме обмена с вашим почтовым сервисом (см. ниже), и не используются для рекламы. В приложении нет аналитики и отслеживания.

Данные нужны только для того, чтобы показать вам ваши траты: суммы, категории покупок и историю чеков.

Данные хранятся, пока почта подключена. Они стираются, когда вы отключаете почту, сбрасываете все данные или удаляете приложение.

Связь с почтовым сервисом

Приложение обменивается данными только с вашим почтовым сервисом (Mail.ru, Яндекс или Gmail) — при входе и при загрузке писем с чеками. К этому обмену применяются правила конфиденциальности почтового сервиса.

Данные из аккаунта Google

Если вы подключаете почту Gmail, приложение получает от Google доступ только на чтение писем (gmail.readonly). Оно читает только письма с кассовыми чеками и сохраняет из них данные чеков на вашем телефоне. Эти данные не передаются разработчику, третьим лицам и не используются для рекламы или обучения моделей ИИ.

Использование и передача приложением Chekly информации, полученной из API Google, соответствуют Политике в отношении пользовательских данных сервисов Google API, включая требования об ограниченном использовании.

Chekly's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Отозвать доступ приложения к Gmail можно в настройках аккаунта Google: myaccount.google.com/permissions.

Приложение ничего не меняет в почте

Приложение только читает письма с чеками: ничего не отправляет, не удаляет и не помечает прочитанным.

Как удалить данные

  • Настройки → «Отключить» у почты: удаляются ключ доступа, адрес этой почты и её чеки. Для Gmail приложение также отзывает доступ в аккаунте Google.
  • Если подключены две почты, кнопка «Сбросить все данные» в Настройках отключает обе и удаляет все чеки.
  • При удалении приложения с устройства удаляются все его данные.
  • Доступ приложения к почте можно отозвать и в настройках безопасности почтового сервиса.
